Не запускай build для перевірки. Використовуй `npm run typecheck`, `npm test` та dev server для перевірки інтерфейсу.

Для нових фіч і виправлень додавай стислий запис у `updates.md`: `(YYYY-MM-DD) - Опис. (type: short description)`.

Після змін самостійно роби коміт з відповідною назвою. Не додавай `.env.local`, ключі або сторонні зміни.
